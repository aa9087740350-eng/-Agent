# 清研霍格精工拓客智能体

## 项目背景

清研霍格精工是一家面向科研与高端制造研发场景的精密制造服务团队，源自清研华科新能源研究院体系，主要服务高校实验室、课题组、科研单位和硬科技初创企业。

这类客户通常不需要传统意义上的大批量标准加工，而是需要高可靠性的单件样件、小批量试制、实验装置、非标夹具、复杂结构件和快速迭代支持。普通加工厂往往不愿承接小单、沟通成本高；小作坊虽然愿意接单，但在精度、交期、稳定性和设计理解能力上存在风险。

本项目目标是构建一个 AI agent，帮助客户经理从公开信息中发现近期有科研样件、实验装置、设计优化或小批量试制需求的潜在客户，并生成可执行的客户开发建议。

## 企业业务定位

清研霍格精工的核心定位是：

> 面向高校科研、科研院所和硬科技团队的一站式精密制造与研发试制服务商。

主要服务能力包括：

- 快速打样：承接单件样件、小批量试制、实验件和验证件。
- 精密机加工：三轴、四轴、五轴加工，适合复杂曲面件和高精度结构件。
- 辅助设计与设计优化：帮助缺少工程制造经验的科研团队优化图纸、结构、公差和可加工性。
- 工装夹具与实验装置：承接非标夹具、测试治具、实验平台、试验台架等定制需求。
- 精密检测：提供尺寸检测、形貌观察、力学测试等制造质量验证支持。
- 学生实践平台：为高校学生提供从设计到加工落地的工程实践支持。

典型产品或加工对象：

- 叶轮、叶盘、叶片
- 精密壳体、连接件、轴类件
- 机器人和无人机结构件
- 新能源结构件、电驱相关试验件
- 半导体设备部件、石墨件、陶瓷/绝缘类零件
- 实验夹具、测试平台、非标工装

## 目标客户

本项目优先开发以下客户：

| 客户类型 | 典型需求 | 开发优先级 |
| --- | --- | --- |
| 高校工科课题组 | 样件、实验装置、测试夹具、结构件 | 高 |
| 科研院所/重点实验室 | 高精度试验件、复杂结构件、科研平台配套件 | 高 |
| 教授创业/成果转化团队 | 原型样机、小批量试制、中试验证 | 最高 |
| 硬科技初创企业 | 快速迭代、设计优化、试产引流 | 高 |
| 跨学科硬件团队 | 微流控模具、缩尺模型、实验平台、定制装置 | 中高 |
| 学生竞赛/创新项目 | 低门槛打样、实践教学、长期关系建立 | 中 |

低优先级或暂缓开发对象：

- 纯理论研究团队
- 纯算法、纯软件、纯仿真团队
- 只采购标准设备、无定制加工需求的团队
- 长期大批量低价加工客户
- 需求明显超出当前加工能力范围的客户

## 客户痛点

目标客户的核心痛点包括：

1. 小批量或单件样件，一般工厂不愿意接。
2. 家庭作坊或低端加工供应商可靠性不足，容易出现精度不稳、延期、返工。
3. 教授、硕士、博士工程实践经验有限，图纸和结构设计中常有加工、装配、公差问题。
4. 科研项目需要快速迭代，设计版本频繁变化，传统供应商响应慢。
5. 论文、答辩、项目验收、结题节点紧，样件交付失败会直接影响科研进度。
6. 很多课题组有实物需求，但缺少稳定、懂科研场景的制造合作伙伴。

## 商业逻辑

### 价值主张

清研霍格精工不是单纯卖加工服务，而是为科研团队提供“从图纸到实物”的研发制造支持。

核心价值：

- 降低科研团队样件制造失败率。
- 缩短从设计到实验验证的周期。
- 帮助学生和课题组提升设计可制造性。
- 支撑高校科研成果从实验室走向样机、中试和产业化。
- 在早期合作中识别高成长性团队，建立长期制造合作关系。

### 盈利模式

1. 小批量订单引流  
   通过单件样件、小批量试制、实验夹具等需求建立初次合作。

2. 设计优化增值  
   对图纸评审、结构优化、工艺建议、装配改进等能力进行服务化包装。

3. 长期课题组合作  
   成为实验室稳定样件供应商，承接持续迭代需求。

4. 成果转化引流  
   在合作过程中锚定有产业化潜力的课题组、教授创业团队和初创企业，为后续批量化生产导流。

5. 行业趋势洞察  
   通过接触前沿科研项目，提前了解机器人、新能源、半导体、航空航天、生物医疗等行业趋势。

## Agent 建设目标

本 agent 的核心任务是帮助客户经理回答三个问题：

1. 今天最该联系谁？
2. 为什么现在联系？
3. 应该怎么开口？

Agent 不应只是生成教授名单，而应识别“近期最可能需要科研样件加工和设计优化服务”的机会线索。

最终输出应包括：

- 高潜客户清单
- 客户优先级评分
- 需求信号和痛点判断
- 推荐联系人
- 推荐切入点
- 邮件/微信/电话触达话术
- 跟进建议
- 后续监控触发条件

## Agent 总体工作流

```text
目标区域与客户画像配置
        ↓
公开线索采集
        ↓
需求信号识别
        ↓
动态评分与优先级排序
        ↓
联系人识别
        ↓
客户卡片生成
        ↓
触达话术生成
        ↓
客户经理人工确认并触达
        ↓
销售反馈录入
        ↓
评分模型和客户画像持续优化
```

### 4. 动态评分模块

建议评分公式：

```text
最终优先级 = 基础匹配分 + 近期紧迫分 + 触达可行性分 + 历史关系分 - 假阳性扣分
```

基础匹配分：

| 维度 | 分值 |
| --- | --- |
| 区域匹配 | 0-20 |
| 机构类型匹配 | 0-20 |
| 学科方向匹配 | 0-20 |
| 显性需求信号 | 0-30 |
| 痛点信号 | 0-30 |

近期紧迫分：

| 近期信号 | 加分 |
| --- | --- |
| 近 1 个月有夹具、加工件、试验台采购公告 | +20 |
| 近 3 个月论文/专利出现“样机”“装置”“结构件” | +15 |
| 项目结题时间在 6 个月内 | +20 |
| 招聘机械设计岗、加工工艺岗、实验工程师 | +25 |
| 新闻出现产业化验证、中试基地、成果转化 | +30 |
| 出现精度不足、变形、返工等痛点词 | +25 |

优先级划分：

| 分数 | 等级 | 动作 |
| --- | --- | --- |
| 90+ | A+ | 本周重点联系，必要时安排拜访 |
| 75-89 | A | 一周内联系 |
| 60-74 | B | 进入触达池，批量邮件/微信触达 |
| 40-59 | C | 持续观察 |
| 40 以下 | D | 暂不推荐 |

### 5. 联系人识别模块

联系人优先级：

| 优先级 | 联系对象 | 理由 |
| --- | --- | --- |
| 1 | 论文中的博士/硕士作者 | 通常直接画图、找加工、推进实验 |
| 2 | 实验室工程师/实验员 | 通常负责装置、设备、加工对接 |
| 3 | 博后/项目助理 | 负责项目推进，响应率较高 |
| 4 | 教授/PI | 适合建立信任，但冷启动回复率低 |
| 5 | 学院科研秘书/平台负责人 | 适合进入学院或共享平台 |

Agent 输出联系人时，应说明推荐原因，而不是只列邮箱。

### 6. 触达话术生成模块

触达原则：

- 从“看到你的需求”开始，而不是从“我们能做什么”开始。
- 必须引用具体信号，例如论文样机、采购公告、成果转化新闻、实验装置图片。
- 用“免费图纸可制造性评审”降低首次合作门槛。
- 对教授强调项目节点、科研可靠性和成果转化。
- 对学生强调图纸优化、快速出件、少返工。
- 对实验室工程师强调工装夹具、检测报告和交付稳定性。
- 对初创企业强调从原型到小批量试产。

话术示例：

```text
王老师您好，我们看到您团队近期展示了柔性抓取机器人样机，其中薄壁铝合金结构件对变形控制和装配精度要求较高。我们长期为高校课题组做单件样件、实验夹具和小批量试制，也可以先免费帮您看一下图纸，提一些可制造性建议。如果近期有样件迭代需求，可以进一步沟通。
```

### 7. 持续监控模块

监控不应产生简单提醒轰炸，而应使用组合触发。

高价值组合信号：

| 组合信号 | 判断 |
| --- | --- |
| 成果转化新闻 + 采购公告 | 可能进入样机/中试阶段 |
| 新论文样机 + 招聘机械设计岗 | 团队正在强化硬件能力 |
| 项目结题临近 + 实验装置采购 | 有赶节点需求 |
| 老客户新论文 + 升级版实验平台 | 复购机会 |
| 采购小型 CNC + 多次出现样件 | 自加工能力可能不足，适合外部合作 |

```text

已报价
已成交
暂不需要
已有固定供应商
自己买了设备
预算不够
只是理论研究无实物
对接人没找对
价格不合适
交期不匹配
```

反馈数据应反向优化评分模型，降低假阳性信号权重。

## MVP 范围

第一版 agent 应优先完成以下能力：

1. 输入目标区域和目标高校。
2. 搜索高校课题组、实验室、采购公告、成果转化新闻。
3. 识别样机、夹具、实验装置、加工痛点等需求信号。
4. 按近期紧迫度和基础匹配度评分排序。
5. 输出 Excel 客户清单。
6. 为每个 A 类线索生成首封邮件和微信开场白。
7. 允许客户经理记录跟进状态和未成交原因。

第一版目标不是自动销售，而是每天给客户经理提供：

```text
今天最该联系的 20 个客户
每个客户为什么值得联系
应该找谁
第一句话怎么说
```

## 后续迭代方向

- 接入更多公开数据源：论文、专利、采购平台、招聘平台、科技园企业库。
- 增加老客户合作记忆，识别复购信号。
- 建立案例库，根据客户需求自动匹配相似加工案例。
- 建立关键词权重学习机制，根据成交反馈调整评分。
- 增加拜访计划生成，根据区域和优先级安排客户经理路线。
- 增加图纸初审流程，把高意向客户引导到免费 DFM 评审。

## 开发原则

1. 需求导向优先  
   不以教授名单为中心，而以“近期样件需求和加工痛点”为中心。

2. 近期信号优先  
   近期采购、论文样机、招聘、成果转化等信号应显著提高优先级。

3. 人工确认触达  
   MVP 阶段不自动发送邮件或微信，所有触达内容由客户经理确认后发送。

4. 可解释评分  
   每个客户分数必须附带评分理由，方便销售判断是否可信。

5. 可追溯来源  
   每条线索必须保留信息来源 URL、采集日期和证据片段。

6. 反馈闭环  
   跟进结果必须回写，用于优化客户画像和评分规则。

## 项目一句话总结

本项目要构建的不是一个“高校教授名单采集器”，而是一个面向科研样件制造场景的“机会识别与客户开发 agent”：它要帮助清研霍格精工找到近期真正有样件加工、设计优化、实验装置和小批量试制需求的客户，并告诉客户经理为什么联系、找谁联系、怎么开口。
