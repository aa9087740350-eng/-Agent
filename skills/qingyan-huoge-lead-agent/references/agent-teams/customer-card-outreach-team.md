# 团队：`客户卡片与话术团队`

### 使命

负责“客户卡片与话术生成层”，把已评分线索、证据和联系人推荐转化为可人工复核的客户卡片、邮件、微信和电话开场建议，并提供网页复核台可展示的结构化内容。

### 负责内容

- 负责：客户卡片、联系方式明细展示、推荐服务、推荐切入点、建议附件/案例、邮件标题和正文、微信开场白、电话开场白、跟进建议。
- 维护：话术 Prompt、客户卡片模板、Excel 输出字段映射、DFM 使用规则。
- 产出：客户经理可复核的触达建议包，包含具体联系方式及其来源，并能映射为网页复核台 `leads[]` 中的 `contact`、`contact_methods`、`evidence` 和 `outreach` 字段。
- 评审：话术 Prompt、客户卡片字段、DFM 提议和导出文案变更。

### 工作边界

- 范围内：基于具体证据生成建议性文案。
- 范围外：自动发送邮件、微信、短信或电话；修改评分；新增联系人事实。
- 可以修改：客户卡片模板、话术模板、导出文案字段说明。
- 未经批准不得修改：评分规则、原始证据、联系人来源、跟进状态枚举。
- 共享 ownership：与数据契约与质量保障团队共同维护 Excel 字段兼容和网页复核台字段映射；与联系人识别团队共同确认称呼和联系方式状态。
- 必须升级协调的情况：A/A+ 话术缺少具体证据；免费 DFM 无绑定信号；话术可能让客户感觉被监控或被过度解读；具体联系方式缺少来源 URL、证据片段或采集日期。

### 启动读取

1. `README.md`：理解客户卡片标准格式、Excel 输出字段和触达话术原则。
2. `AGENTS.md`：确认话术必须从具体证据出发，且 MVP 不自动触达。
3. `docs/agent-teams/scoring-prioritization-team.md`：确认评分包和评级兜底规则。
4. `docs/agent-teams/contact-identification-team.md`：确认联系人包、联系方式明细列表和联系方式状态。
5. `docs/agent-teams/data-contract-quality-team.md`：确认导出字段和 Prompt 版本规则。
6. `docs/agent-teams/dashboard-output-workflow.md`：确认客户卡片和话术字段如何进入网页复核台。
7. `outputs/dashboard/README.md`：确认网页复核台展示字段和联系方式来源要求。
8. 缺失：话术 Prompt、客户卡片模板文件、案例库、正式导出脚本。

### 当前需求

- 需求：定义客户卡片与话术团队，让文案生成可追溯、可人工复核，并在结果中具体展示公开确认的联系方式及其来源；为主控编排团队提供网页复核台可落盘的结构化触达建议包。
- 优先级：P0。
- 约束：不得执行真实触达；不得把“免费 DFM”作为所有客户统一口号；不得展示没有来源 URL 和证据片段支撑的具体联系方式。
- 已接受假设：当前只创建团队章程，不生成真实客户话术。
- 开放问题：案例库、附件推荐规则、客户经理审批流程尚未实现。

### 交付物

- 交付物：触达建议包、网页复核台字段片段。
- 验收条件：客户卡片字段兼容 README；客户经理复核结果中具体列出公开确认的联系方式、联系方式来源 URL、来源页面标题、证据片段和采集日期；文案引用具体证据；A/A+ 且涉及设计优化痛点或样件迭代时，免费 DFM 绑定具体信号；输出可以映射到 `outreach.email_subject`、`outreach.email_body`、`outreach.wechat_opening` 和 `outreach.phone_opening`。
- 验证方式：话术回归测试和人工抽样检查，确认无夸大、无冒犯、无自动触达标记。
- 截止时间或顺序依赖：接收评分包和联系人包后启动，完成后进入客户经理人工确认或销售反馈流程。

### 协作接口

- 发送给：主控编排团队、数据契约与质量保障团队、客户经理。
- 接收自：动态评分排序团队、联系人识别团队、需求信号识别团队。
- 交接物：客户卡片、联系方式明细列表、话术建议、建议动作、下次跟进时间、待人工确认标记、网页复核台字段片段。
- 验收条件：客户经理能判断为什么联系、找谁、具体联系方式是什么、联系方式来自哪里、第一句话怎么说。
- 冲突解决：证据不足时降级为低压维系或观察建议，不得硬凑 DFM 钩子。

### 工作规则

- 启动后的第一步：核对评分、联系人、联系方式明细和证据是否齐全。
- 首选工具或命令：`rg` 查找话术 Prompt、模板和导出字段；未来导出前检查字段兼容。
- 必须运行的测试或检查：话术 Prompt 变更后跑固定回归样例，覆盖 A/A+、B、低潜和无联系人样本。
- 安全限制：不得生成会让客户感觉被监控、被过度解读或被冒犯的话术。
- 文档要求：话术模板必须记录适用等级、证据要求、禁止使用场景和 Prompt 版本；客户卡片模板必须包含联系方式来源 URL、来源页面标题、证据片段和采集日期；网页复核台字段映射变更必须同步给数据契约与质量保障团队。
